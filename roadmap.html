6G Intrusion Detection & Privacy Preservation

Final Synopsis Implementation Roadmap & Execution Workflow

1
Network Flow Ingestion & Cleaning Completed
Ingested full 80-feature CSE-CIC-IDS2018 telemetry flow schema into data/raw/. Performed normalization of header names, string stripping, and mapped attacks into binary classification targets (BENIGN vs ATTACK).

Artifacts Generated:

  • Raw benchmark CSV: data/raw/cse_cic_ids2018_dataset.csv (15,000 flow rows)
  • Cleaning Script: src/data/preprocessing.py
2
Stratified Preprocessing & Feature Selection Completed
Applied SelectKBest feature selection to extract the top 40 predictive flow features. Fitted median imputation and standard scaling strictly on training rows to prevent test-set data leakage.

Artifacts Generated:

  • Preprocessed NumPy Arrays: data/processed/dataset.npz
  • Saved Scaler & Imputer: models/preprocessor.joblib
  • Selected Features Manifest: models/selected_features.json
3
Centralized 1D-CNN Baseline Training Completed
Built a 1D Convolutional Neural Network (1D-CNN) with Conv1D, BatchNormalization, Dropout, and Sigmoid classification. Trained on pooled data to establish a non-federated baseline.

Artifacts Generated:

  • Saved Model: models/centralized_model.keras
  • Metrics JSON: metrics/centralized_metrics.json
  • Plots: ROC curves & Confusion matrices in plots/
4
Simulated Edge Federated Learning (FedAvg) Completed
Partitioned telemetry across simulated edge clients using label-skewed Non-IID distributions. Evaluated local client training and central coordinator aggregation over 5 rounds using sample-weighted FedAvg.

Artifacts Generated:

  • Federated Model: models/federated_model.keras
  • Federated Metrics: results/federated/federated_metrics.json
5
Differential Privacy (DP) Perturbation Completed
Integrated client-update differential privacy by clipping parameter deltas to L2 norm bound (C=1.0) and adding independent Gaussian noise (σ=1.0) prior to FedAvg aggregation.

Artifacts Generated:

  • DP Federated Model: models/federated_dp_model.keras
  • DP Metrics: results/differential_privacy/federated_dp_metrics.json
6
Interactive Streamlit Web Dashboard Completed & Live
Constructed a dark-mode 6G cyber security web dashboard featuring real-time CSV threat prediction, Plotly comparative charts, feature badge lists, and architectural workflow visualization.

Deliverable URL:

  • Dashboard App: app.py running at http://localhost:8501
